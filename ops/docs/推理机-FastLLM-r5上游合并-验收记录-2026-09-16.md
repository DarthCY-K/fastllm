## 6. 方法学（本轮新增纪律）

1. **单次采样差不得当回归**：长上下文 decode 必须 ≥3 重复 + 输出 md5 逐字节对齐（同内容）才可比较，并用 prod 两头做自身漂移带。
2. **接受率随窗口推进单调变化**：位置/热效应，不可据此给构建记功或记过。
3. **内存探针拆 pass1/pass2**：整体增长会把「首段分配预热」读成泄漏；稳态率才是判据。
4. **soak 脚本 `build=` 标签是硬编码**：转正后必须同步改，否则日志留下不实记录。
5. **身份核对用 `git show HEAD:<path> | sha256sum`**（LF blob）口径，别用 Windows 工作区直接哈希。
6. **清理与启动分两次调用、按 PID 杀**：同一 ssh 命令行里既写 `pkill -f '<script>.sh'` 又写 `bash <script>.sh` 会自杀（本轮真踩）。
