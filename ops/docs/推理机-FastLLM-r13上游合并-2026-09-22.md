## 6. 观察项闭环（2026-09-22 23:30）

### 6.1 `nvfp4_planar` block16 位差 — 判定：宿主指令集路径的最后一位差异，非数值错误、非本批引入

- 本机 CPU = **AMD EPYC 7K62（Zen 2）→ `AVX512F/BF16 = OFF`**，测试全程走 `avx512=0`（AVX2）分支。
- 失败的是**唯一一条位级严格断言**：同一 GEMM 的 legacy row-major block16 与 planar block16 两种物理布局必须 `memcmp` 全等（`test_nvfp4_planar.cpp:247`）。二者最后一位不同 ⇒ 两种布局的规约/累加次序不同，属实现细节差异。
- **同文件的数值正确性断言全部通过**（`block16 BF16 GEMM disagrees with FP64 reference` 未触发；`columns=17/33/128/640 × cross_swiglu=0/1` 八组 `equal storage and weight/scale bits; CPU outputs agree` 全 PASS）。
- r12 与 r13 日志**逐行同形**（首行同一条 FAIL，其余同）；该测试文件最后一次变更是上游 `d7caee7b`（09-21 紧凑 NVFP4 E4M3 专家权重），不在我们线上改动范围。
- 生产影响：无。生产解码走 GPU NVFP4 CUDA 核；CPU planar GEMM 不在服务路径上，且生产输出与 r8–r12 探针 md5 逐位一致。
- 可选项：向上游反馈「AVX2 宿主上 block16 双布局位级等价不成立」（若要提就是独立小 issue，不影响我们）。
